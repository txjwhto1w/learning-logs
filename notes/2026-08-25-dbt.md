# 2026-08-25

## dbt incremental materialization

- `incremental_strategy` options: `delete+insert`, `merge`, `append`
- Use `is_incremental()` to limit processing to new rows
- For `merge`, define `unique_key` to handle updates
- `append` is fastest but doesn't handle updates

## DuckDB

- Querying Parquet directly: `SELECT * FROM 's3://bucket/*.parquet'`
- `duckdb` CLI works well for quick local exploration
